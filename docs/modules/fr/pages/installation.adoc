= Installation

== Prerequis

* Crystal >= 1.19.0

== Ajouter la Dependance

Ajoutez crystal-asciidoctor a votre `shard.yml` :

[source,yaml]
----
dependencies:
  crystal-asciidoctor:
    github: aloli-crystal/crystal-asciidoctor
----

Puis lancez :

[source,bash]
----
shards install
----
