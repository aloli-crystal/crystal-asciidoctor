= Installation

== Prerequis

* Crystal >= 1.19.0

== Ajouter la Dependance

Ajoutez asciicrystal a votre `shard.yml` :

[source,yaml]
----
dependencies:
  asciicrystal:
    github: aloli-crystal/asciicrystal
    version: "~> 2.0.26.12"
----

Puis lancez :

[source,bash]
----
shards install
----
