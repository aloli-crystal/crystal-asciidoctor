= Installation

== Requirements

* Crystal >= 1.19.0

== Add the Dependency

Add asciicrystal to your `shard.yml`:

[source,yaml]
----
dependencies:
  asciicrystal:
    github: aloli-crystal/asciicrystal
    version: "~> 2.0.26.12"
----

Then run:

[source,bash]
----
shards install
----

== Dependencies

This shard depends on:

* https://github.com/aloli-crystal/rouge[rouge] (~> 4.7.0.3) -- syntax highlighting
